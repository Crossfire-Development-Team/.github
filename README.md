# Organization profile · Crossfire Development Team

This repository contains the public GitHub profile of the
[Crossfire Development Team](https://github.com/Crossfire-Development-Team),
part of the SWAT-Portal community.

It holds presentation content, not game or server source code.

## Contents

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Team introduction displayed on the organization's Overview page |
| [`profile/crossfire-team.png`](profile/crossfire-team.png) | Team logo used in the profile; kept below 1 MB |

## Why this repository is public

GitHub requires a public repository named `.github` with a `profile/README.md`
to display a public organization profile. The repository therefore remains
visible in the repository list. Its name and visibility are intentional.

See [GitHub's organization profile documentation](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).

## Updating the team page

Edit `profile/README.md` to change the public introduction. Replace the logo at
its existing path to update the image. Changes on `master` update the profile.
Keep all content suitable for public viewing; do not add internal development
details, credentials, or personal player data.

Issues, Projects, Wiki, Discussions, Downloads, and GitHub Actions are disabled
because this repository only hosts profile content. GitHub Pages is not configured.
Pull requests remain available for reviewing profile changes.

For Crossfire information and community support, visit
[SWAT-Portal](https://swat-portal.com/forum/).
